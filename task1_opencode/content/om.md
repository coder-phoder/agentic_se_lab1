## What I think about AI in software engineering today
AI writes code very fast, but it also writes unsafe code very fast. I have seen it suggest passwords directly in the code. It is useful, but only if you know enough to see the mistakes.

## Where software engineering will be in 5–10 years
AI agents will check the code of other AI agents for security problems. Developers will need to know about new attacks like prompt injection. Less people will write code, more people will check it.

## My hot take on AI
The first big AI agent hack has not happened yet. But it will come, and it will start with a README file.
